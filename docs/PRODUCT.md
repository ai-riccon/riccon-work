# 产品

私有化优先的多租户企业 AI 协同办公系统。办公套件做入口，平台做内核；v1 只证明员工侧价值。

## 1. 目标

企业员工现在要在多个系统之间搬运文件、查资料、找数据、拼报告，过程不可追溯，结果无法复用。Riccon 把这件事收进一个租户隔离的云工作空间：员工上传办公文件、提问、调用已授权工具、在关键动作上审批，Agent 产出带引用的回答与可保存的报告；平台侧统一管理模型、知识库、MCP 与权限，并留下可审计的记录。M02 要证明的不是"能聊天"，而是"员工的一条完整办公任务能在可审计、可隔离的前提下跑完"。

## 2. 用户

| 用户            | 场景                                           | M02 覆盖 | 说明                                                                      |
| --------------- | ---------------------------------------------- | -------- | ------------------------------------------------------------------------- |
| 企业员工        | 上传文件提问、发起市场调研报告、查看与复用产物 | 是       | v1 唯一被证明的使用者                                                     |
| 部门/团队负责人 | 管理本部门共享空间、Agent 与成员可见范围       | 部分     | M02 只有基础角色；数据范围与共享管理在 M03                                |

| 企业 IT 运维    | 私有化部署、备份、升级与回滚                   | 否       | 只消费 M09 交付物，不参与 M02                                             |

## 3. MVC：J1 + J2

MVC 是两条相连的员工旅程：J1 解决"我的文件能不能被理解和引用"，J2 解决"一次带外部数据与人工审批的任务能不能产出可交付报告"。J2 复用 J1 的文件与引用能力，因此两条旅程共同构成一条关键旅程。

### J1 通用问答与文件处理

**输入**

- 员工用租户内账号登录，进入云工作空间并新建会话。
- 上传 PDF、Word（.docx）、Excel（.xlsx）、PNG/JPEG 文件；M02 默认单文件 ≤ 200 MB、单次会话 ≤ 5 个文件。
- 用自然语言提问，问题可指向某个已上传文件，也可指向租户知识库。

**可见产物**

- 每个文件有明确的解析状态：处理中、成功、失败（含原因与下一步）。
- 提交问题后 3 秒内出现首字，回答流式增长；员工可中途停止，已生成内容保留。
- 回答附带引用列表，每条引用可定位到文件名与页码/工作表/段落；点击可打开对应位置。
- 知识库无命中时明确提示"未检索到相关资料"，不展示伪造引用。
- 会话与上传文件保存在工作空间，可再次打开并继续提问。
- 失败态：不支持的格式、超限、解析失败、模型失败，均显示原因与可重试入口，且不丢失已上传文件。

**必须存在的证据**

- 一条可回放的 E2E 记录：登录 → 上传 → 解析成功 → 提问 → 首字 → 引用 → 停止 → 重新打开会话。
- 会话运行详情中可见模型调用记录：模型标识、开始/结束时间、结果状态。
- 审计记录覆盖文件上传、文件删除、会话创建、模型调用。
- 引用与源文件的对应关系可在界面上复现，不依赖测试代码或日志推断。

### J2 市场调研报告

**输入**

- 员工在工作空间新建"市场调研报告"任务，输入主题（例：某行业市场规模与竞争格局）。
- 选择一个已授权给本租户的 MCP 工具用于取数；M02 只要求 1 个工具。
- 任务运行到工具调用前，员工收到审批请求。

**可见产物**

- 任务详情显示当前阶段：检索 → 工具取数 → 审批 → 生成报告，阶段切换可见。
- 检索阶段展示命中的资料条目、来源与片段，并标注引用。
- 工具阶段展示 1 次 MCP 调用记录：工具名、入参摘要、结果摘要、耗时、状态；失败时显示原因并可重试该阶段。
- 审批节点展示将要执行的动作、目标工具与数据范围；员工批准后继续，拒绝后任务终止，记录审批人与时间。
- 报告产物保存在工作空间，含标题、摘要、分节正文、引用清单、数据来源；可再次打开，引用清单中的每条来源都能在运行记录中找到。
- 失败态：检索无结果提示调整主题且不进入生成；MCP 超时、审批拒绝、报告生成失败均有明确状态、保留已完成阶段记录、可重试且不产生重复产物。

**必须存在的证据**

- 任务时间线：检索查询与命中、MCP 调用（工具、入参摘要、结果摘要、耗时、状态）、审批（人、时间、决定）、模型调用、产物版本。
- 审计记录覆盖 MCP 调用、审批动作、产物保存。
- 产物引用清单与任务时间线一一对应，可人工抽查。
- 两条 E2E 路径：审批通过产出报告；审批拒绝终止且无产物。

### M02 范围边界

- 包含：内置账号登录、租户与基础 RBAC、云工作空间、J1、J2、模型网关最小闭环（单一 OpenAI 兼容端点）、审计写入、基础可观测性。
- 不包含（按路线图后移）：OIDC/SSO 与部门数据范围（M03）、模型路由与配额（M04）、文档级 ACL 与 OCR（M05）、MCP 注册审批与凭据托管（M07）、可视化编排（M06）。

## 7. M02 验收标准

编号用于任务拆解与 verifier 逐条对账；每条至少对应一条 E2E 或集成测试。AC 不规定实现方式。

| ID        | 验收标准（Given / When / Then）                                                                                                                                                                       | 验证       |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| M02-AC-01 | Given 员工属于租户 A 且账号已启用；When 用正确凭据登录；Then 进入租户 A 的工作空间并显示租户名；错误凭据只显示统一失败提示，不泄露账号是否存在。                                                      | E2E        |
| M02-AC-02 | Given 员工在会话中；When 上传 PDF、DOCX、XLSX、PNG、JPEG 各一个且均 ≤ 200 MB；Then 每个文件显示解析状态并在成功后可用于提问；不支持格式或超限被拒绝并提示原因。                                       | E2E        |
| M02-AC-03 | Given 会话中有 1 个解析成功的文件；When 提交与该文件相关的问题；Then 3 秒内出现首字（假模型基准），回答逐步增长；中途停止后已生成内容保留。                                                           | E2E        |
| M02-AC-04 | Given 回答使用了知识库内容；When 查看引用；Then 每条引用显示文件名与定位（页码/工作表/段落）且可打开对应位置；无命中时提示未检索到资料，不出现伪造引用。                                              | E2E        |
| M02-AC-05 | Given 文件解析失败或模型调用失败；When 员工查看会话；Then 显示失败原因与重试入口，已上传文件与已有消息不丢失。                                                                                        | E2E        |
| M02-AC-06 | Given 员工有创建报告权限；When 输入主题并提交；Then 任务进入运行中状态，并显示当前阶段（检索/工具/审批/生成）。                                                                                       | E2E        |
| M02-AC-07 | Given 任务进入检索阶段；When 检索完成；Then 展示 ≥ 1 条来源、标题与片段并带引用；无结果时提示调整主题且任务不进入生成。                                                                               | E2E        |
| M02-AC-08 | Given 任务进入工具阶段；When 调用已授权的 MCP 工具；Then 任务详情显示工具名、入参摘要、结果摘要、耗时与状态；失败显示原因且可重试该阶段。                                                             | E2E        |
| M02-AC-09 | Given 工具调用需要审批；When 审批未完成；Then 任务不生成报告；批准后继续，拒绝后终止并记录审批人、时间与决定。                                                                                        | E2E        |
| M02-AC-10 | Given 审批通过且报告生成成功；When 员工打开产物；Then 产物含标题、摘要、分节正文、引用清单与数据来源，可再次打开，且引用清单每条都能在任务时间线中找到。                                              | E2E        |
| M02-AC-11 | Given MCP 超时或报告生成失败；When 员工查看任务；Then 任务标记失败、保留已完成阶段记录、可重试，且重试不产生重复产物。                                                                                | E2E        |
| M02-AC-12 | Given 租户 A 员工持有租户 B 的会话、文件或产物标识；When 直接访问；Then 返回统一的拒绝响应，不返回任何 B 的内容，也不泄露对象是否存在。                                                               | E2E + 集成 |
| M02-AC-13 | Given 两租户各有会话、文件、产物与工具授权；When 运行越权测试套件；Then 跨租户列表、检索、对象读取与管理接口用例全部通过，零 skip、零 xfail。                                                         | 集成       |
| M02-AC-14 | Given 一次完整 J2 任务；When 任务结束；Then 登录、文件上传/删除、会话创建、模型调用、MCP 调用、审批与权限变更均产生审计记录（租户、操作者、动作、目标、时间、结果）；审计写入失败时对应业务请求失败。 | E2E + 集成 |
| M02-AC-15 | Given 审计记录已产生；When 员工或管理员尝试删除/修改；Then 界面与接口均无此能力；普通员工无法访问审计接口。                                                                                           | 集成       |
| M02-AC-16 | Given 工作空间、会话、任务详情、产物四个界面；When 分别处于加载、空、错误、成功与无权限状态；Then 各有明确文案与下一步；375 px 宽度无横向滚动；仅用键盘可完成登录、上传、提问与审批，焦点可见。       | E2E        |
