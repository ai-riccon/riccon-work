# DEC-0035：M05 阶段预算：M05 + gate 债务先行，M05b 分阶段

## 问题

M05 规划已完成两轮独立 Verifier 评审并收口（ADR-0023 / PRODUCT §11）。最终估算：M05 104h（Excel/OCR/ACL/delete-reindex/流式下载/审计/注入/perf/OCR 镜像/独立验证），M05b 53h（S3 连接器），M05 gate 前置债务 M23 6h（M13 F-001 部门字段）+ M24 20h（M04 F-006/F-008/F-010/F-012、M22 F-001、M20 F-004、R-M04-03）。是否批准，以及是否一次批准 M05b？

## 选项

- A（推荐）：阶段批准。先做 M23 6h + M24 20h + M05 104h = 130h；M05 用户验收后再批 M05b 53h。M05 超 125h、M24 超 24h、M23 超 8h 暂停；检索 p95 >500ms 触发 FTS/OpenSearch 时另立决策。
- B：一次批准全部。M05 104h + M05b 53h + 债务 26h = 183h；M05b 仍在 M05 用户验收后启动。
- C：只批 M05 104h。M23/M24 延后并书面接受 M05 gate 债务（不推荐；M05 gate 将不满足）。
- D：缩减范围/延后。列出移除项（如扫描 PDF OCR、AC-17/18、连接器延后），需合同/路线图变更。

## 建议

A：分阶段与 M05/M05b 拆分一致；M05b 外部依赖与凭据风险最高，等 M05 验收后再承诺；债务必须先于 M05 gate 关闭。

## 后果

A 先承诺 130h，M05b 可复盘；B 一次承诺 183h；C 带 gate 债务风险；D 缩小合同 M05 范围。所有估算不含跨会话协调与评审包，按暂停阈值控制。
