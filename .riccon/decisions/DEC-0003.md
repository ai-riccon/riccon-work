# DEC-0003：MySQL Connector/J 许可

## 问题

MySQL Connector/J 为 GPLv2 + FOSS exception；产品私有化分发需要商业许可或替换驱动。选哪个？

## 选项

- A 切换 MariaDB Connector/J 3.x（LGPL-2.1），M02 做 MySQL 8.4 兼容 spike
- B 采购 Oracle MySQL 商业许可
- C 暂用 Connector/J，发布前再决策（不推荐）

## 建议

A

## 后果

A 需要驱动切换与兼容性验证，但不引入 GPL 分发义务；B 有采购成本；C 把法务风险留到发布前。
