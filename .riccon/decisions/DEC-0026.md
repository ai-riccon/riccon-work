# DEC-0026：测试基础设施与全量测试提速路线 P0–P4

## 问题

是否接受只读分析中的 P0–P4 路线，并在 M04 模块 gate 通过后启动 M19（测试基础设施与全量测试提速）？路线：P0 计时与预算；P1 CI 复用 compose 热栈（external+namespace）；P2 CI 4-shard 分片与合并报告；P3 Worker 租户级隔离/API fixture 缓存；P4 测试分层与纯逻辑下沉。约束：不减少 771 个用例、零 skip、不降低断言；P1/P2 不改 commands.test；若 gate 需要分片命令，另提合同决策。

## 选项

- A 接受 P0–P4，M04 gate 后启动 M19，预算 16h（推荐）
- B 只做 P0–P2（测量/热栈/分片），P3/P4 暂缓
- C 暂不启动，仅保留分析

## 建议

A：P0–P2 无需改测试代码即可把 CI 墙钟降到 ≤5 分钟；P3 再降 setup 成本；全程不减少用例，风险可控。

## 后果

批准后创建 M19（kind fix，depends_on M04，16h）与 P0/P1/P2 任务；M04 gate 前不开始写 CI/测试文件，避免与 B10/B11/V1 写范围冲突；若后续要分片 gate 命令，另提合同决策。

## 默认

不启动 M19；仅保留只读分析，M04 继续。
