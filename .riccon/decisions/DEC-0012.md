# DEC-0012：B-06 MCP CVE 例外到期处置

## 问题

agentscope 2.0.5 是最新稳定版，2.1.0-BETA1 仍依赖 MCP SDK 0.17.2（0.17.x 末版），升级无法消除 CVE-2026-35568/34237；MCP client 又是 J2 必需。M03 gate 前如何处置？

## 选项

- A 重开 ADR-0011，维持有期例外至 2027-03-31 或 M07 gate（取早），补偿控制不变：仅 client、无入站 server、沙箱禁网、工具白名单、全量 HITL
- B 移除 MCP client 依赖，砍掉 J2 的 MCP 工具能力
- C 自行 fork/patch MCP SDK 0.17.2 删除 server 侧传输，维护成本自担
- D M03 gate 不通过，等上游 agentscope 升级后再继续

## 建议

A

## 后果

A 保留 J2 能力并维持补偿控制，但把风险窗口延到 M07；B 直接损失 MVC 的 MCP 能力；C 引入长期维护分叉且需重新安全评审；D 阻塞 M03 gate 与后续模块。
