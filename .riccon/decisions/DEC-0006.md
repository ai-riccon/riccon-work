# DEC-0006：修正 commands.install

## 问题

pnpm -w install --frozen-lockfile 在 pnpm 10 只安装 workspace root，干净 checkout 下 apps/web 依赖缺失。是否改为 pnpm install --frozen-lockfile？

## 选项

- fix：改为 pnpm install --frozen-lockfile（推荐）
- keep：保留现命令，并在 CI/文档中额外要求 pnpm -r install

## 建议

fix

## 后果

fix 让干净 checkout 可复现；keep 需要额外步骤且容易漏。

fix（可逆；24h 未答复按 fix）
