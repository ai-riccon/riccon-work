# DEC-0033：M20 用户最终验收：成本修复与租户过滤安全

## 问题

M20（fix M04）已 gate PASS（REV-M20-001）、Product 预验收 pass（with residual F-001），7 个任务 done，M20 已标 done（user pending）。是否接受 M20 技术验收，并允许进入 M05（知识库纵深）？M20 不改变用户可见 AC；F-001 价格快照成功终态读取为 accepted residual（M05+ 价格维护/批量改价前重访 ADR-0022 §2.1）；F-002 3s 证据为真实 MySQL 提示+真实服务/HTTP 映射而非生产聚合 SQL 本身；F-004 CostPage 无专门契约断言；ADR-0022 Context 摘要仍写“统一 404”。

## 选项

- A 接受 M20 技术验收（推荐）：记录 user_status=accepted，进入 M05 计划；残余按 owner/due 跟踪
- B 有条件接受：列出条件；未满足前不启动 M05
- C 拒绝 M20：记录原因，保留证据，用 fix 模块处理，不进入 M05

## 建议

A：M20 已通过独立模块 gate 与 Product 预验收；全量 test/coverage/E2E/a11y/security 通过，无用户可见 AC 降低；残余有 owner/due，不改变技术验收。

## 后果

A 允许进入 M05；B 暂停 M05 并补条件；C 保留 M20 done 但 user rejected，需建 fix 模块。

## 默认

无默认：用户最终验收必须明确回答；沉默不标 accepted、不启动 M05。
