# DEC-0044：M25（M05b S3 连接器）用户最终验收

## 问题

M25 14/14 任务 done，模块 gate pass，Product 预验收 pass（with residual R-M25-01..11），独立模块评审 REV-M25-001 pass、无 P0/P1。已答复的 DEC-0042=A（endpointId 文本输入）与 DEC-0043=A（ACL 写 p95 residual）已计入。尚有两条 P2 原定用户验收前处理：F-002 perf 报告 reproduceCommand/env 仍写 aclWriteVus=1（不能照抄复现 passed 矩阵；EV-1002 的 command 字段本身正确）；F-003 O2b RUNBOOK 误删恢复路径与维护账号最小 DB 权限未修订。其余为 P3 文案/证据/治理残余（J2 审批前 source_version、KB-502 非 404、parseEngine=NONE、纯文本分块上限、关闭开关语义、ADR-0023 proposed、Trivy 未录 M25 EV、PAUSED nextSyncAt）。M25 最终验收如何处理？

## 选项

- A（推荐）：accepted with residuals。接受 R-M25-01..11（含 F-002/F-003 P2），owner/due 保留到 M09/release 或后续维护，不新增预算；M25 记录 user=accepted、DEC-0044，进入下一模块。
- B：conditional。先修 F-002/F-003（预计 2–3h，需开 fix 模块/任务并重跑相关校验），修完再 accepted；M25 保持 done 但不启动下一用户可见模块。
- C：rejected。列出阻塞项（如要求 v1 内实现端点目录、KB-404、source_version 或 ACL 写达标），M25 不 accepted，不进入下一模块。
- D：其它（请说明）。

## 建议

A：F-002/F-003 均为可复现性/运维文档残余，不改变连接器用户可见结果或本轮性能结论；F-002 的权威命令在 EV-1002 已带 PERF_M05_ACL_WRITES=0；F-003 的生产调度与首次 apply 本就归 M09。若你要求 v1 前修，选 B 并追加 2–3h。

## 后果

A：M25 user=accepted，可继续下一模块；B：M25 conditional，新增 fix 与复验，用户验收延后；C：M25 rejected，需重新界定范围/预算；D：按你的说明处理。
