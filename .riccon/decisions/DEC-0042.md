# DEC-0042：M05b 连接器端点 allowlist 的 UI 选择口径

## 问题

B8b 评审发现：M05-AC-10 写“从部署 allowlist 选择端点”，但 1.5.0-m05b 没有端点目录 API；B8b 当前用 endpointId 自由文本输入，后端仍按部署 allowlist 强制校验。V1b 前必须定口径：修订 AC 接受文本输入，还是新增只读端点目录 API？

## 选项

- A（推荐）：修订 M05-AC-10/Product 措辞为“管理员输入 endpointId，后端按部署 allowlist 校验；v1 不提供目录选择”；B8b 现状保留，不新增契约/预算。
- B：新增只读端点目录 API（GET /api/v1/knowledge/connectors/endpoints，只返回 id/label/production，不返回 URL），契约新增版本 1.5.1-m05b，B2b/B6/B8b 追加约 4h，M25 预算 56h→60h；V1b 延后。
- C：保留 AC 字面，接受 UI 自由输入为 known gap，V1b 不断言 selector；在 M25 gate/ACCEPTANCE 记录 residual，后续版本再补。

## 建议

A：安全边界由服务端 allowlist 强制，文本输入不削弱安全；v1 不为此新增契约/预算，UX 可在后续版本补目录选择。

## 后果

A：AC 修订，无新增工作；B：新增契约/API/UI 与预算，V1b 延后；C：AC 不修订但保留 residual，V1b 需避开 selector 断言。

## 默认

无默认：产品 AC 与契约口径由用户决定。
