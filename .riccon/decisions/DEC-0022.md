# DEC-0022：合同命令合并：test 与 coverage 共用同一条 coverage 全量命令

## 问题

用户已明确批准以下变更：将 commands.test 与 commands.coverage 改为同一条 coverage 全量命令（./mvnw -q -T1C verify jacoco:report && pnpm -w test -- --coverage），模块 gate 的 test 和 coverage 共用同一条 EV，避免同一提交跑两遍全量。是否按此修改 Project Contract？用户批准原文：『模块 gate 的 test 和 coverage 合并为同一条 coverage 全量命令。』

## 选项

- approve：按用户批准合并 test/coverage 命令并更新合同哈希
- reject：保持两条独立命令

## 建议

approve：用户已明确批准，合并后减少一次全量运行并保持同一 EV

## 后果

contract commands 变更，需 contract sync；后续模块 gate 只跑一次 coverage 全量；不影响 build/test_e2e/a11y/security 命令

## 默认

（无）

- 时间：2026-11-20T01:30:20.672+08:00

用户批准：『模块 gate 的 test 和 coverage 合并为同一条 coverage 全量命令。』据此 commands.test 与 commands.coverage 统一为 ./mvnw -q -T1C verify jacoco:report && pnpm -w test -- --coverage；不涉及 release 环境。
